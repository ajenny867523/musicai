📖 專案架構與前端設計說明

本專案為針對 YuE2-3B 音樂生成工作站 打造的獨立 Web 前端介面，符合課程作業要求的純前端架構（HTML5 + CSS3 + Vanilla JavaScript），並透過非同步 Client 端調用 Hugging Face 深度學習模型 API。

🌐

語意化前端 (Semantic UI)

純 HTML5 與現代 CSS Grid / Flexbox 響應式排版，不依賴龐大框架，輕巧流暢。

🎨

設計系統 (Design Tokens)

集中於 style.css 的 CSS 自訂變數，便於客製化深色主題、漸層光暈與毛玻璃效果。

⚡

非同步 API 連接

前端利用 Hugging Face 官方 @gradio/client 連接雲端 GPU 伺服器進行推論。
